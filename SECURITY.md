# Security Policy

## Supported Versions

`mesh-alerts` is under active development. Until the first stable release, security fixes are applied to the current development branch when appropriate.

| Version | Supported |
| ------- | --------- |
| Development branch | Yes |
| Pre-release versions | Best effort |
| Stable releases | As specified in each release |

## Reporting a Vulnerability

Please **do not report security vulnerabilities in public issues or discussions**.

Use GitHub's **Private vulnerability reporting** feature for this repository, if available. This allows you to submit vulnerability details privately to the maintainers.

When reporting a vulnerability, please include:

- A description of the issue and its potential impact.
- Steps to reproduce the issue, if known.
- Affected versions or commits.
- Any suggested mitigation, if available.

Please avoid including real credentials, access tokens, personal data, or other sensitive information beyond what is strictly necessary.

### Response and Disclosure

Reports will be reviewed as soon as reasonably possible. There is currently no guaranteed response or remediation timeframe.

The maintainers will assess the report, may request additional information, and will communicate whether the issue is accepted as a valid vulnerability and what remediation steps are planned, where applicable.

Please allow maintainers a reasonable opportunity to investigate and address a vulnerability before publicly disclosing it.
